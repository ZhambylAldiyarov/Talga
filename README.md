# Feed The Pelmeni Hero 🥟

Интерактивная веб-игра для GitHub Pages.

## Содержимое проекта
- `index.html` — разметка игры
- `style.css` — стили и анимации
- `script.js` — логика, динамическая смена состояний и звуковые эффекты
- `assets/` — нарезанные реальные фотографии персонажа (`character_hungry.png`, `character_eating.png`, `character_sleeping.png`)
